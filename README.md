## 安装

1. 安装 BepInEx 5(Mono 版，例如 BepInExPack 5.4.2305):解压后，把 `BepInExPack` 文件夹里的**内容**复制到游戏目录(`How to Fish.exe` 所在的文件夹)。
2. 把 `HowToFishTrainer.dll` 放进 `游戏目录\BepInEx\plugins\HowToFishTrainer\`。
3. 通过 Steam 启动游戏。弹出 BepInEx 控制台窗口就说明加载成功了。

卸载：删除 `BepInEx\plugins\HowToFishTrainer\` 文件夹即可。

## 什么时候能用

打开菜单后，顶部的状态栏会显示是否可用。只有以下两种情况会解锁:

- **单人对局：** 你是房主，并且没有其他人连进来。
- **全员同意房间：** 房间里每个人都装了这个 mod,并且各自在菜单顶部勾选了"我同意在本房间使用修改器"。
  - 同意状态写在每个人自己的 Steam 大厅成员数据里，别人没法代你同意。
  - 游戏里实际连进来的每一个玩家，都必须是已同意的大厅成员。
  - 有人没装 mod、没勾选、取消勾选，或者有不经过 Steam 大厅的连接时，立刻锁定。
  - 换房间后同意会自动取消。
  - 局域网直连这类不走 Steam 大厅的联机方式无法验证，一律锁定。

锁定时所有功能开关都会被清空，重新解锁后需要再打开。

解锁后，还需要勾选"启用修改器"才会生效。

### 仅房主可用的功能

以下功能修改的是服务器上的数据，只有房主能用，其他人的菜单里会显示为灰色，并标注 [仅房主]:

金钱、解锁全部皮肤、清理地上物品、无视 Boss 无敌、锁血、锁饱食度、赌场、老虎机、生成鱼类/生物。

其余功能每个人都可以用。

## 功能

### 金钱 / 世界
- **+9999 / +99999 金钱、解锁全部皮肤** [仅房主]
- **清理地上物品** [仅房主]:移除散落在世界里的物品，包括生物尸体。以下物品不会被清理：手上的、物品栏里的、鱼钩上的、鸟叼着的、赌桌上的、活着的生物、任务物品、玩家尸体。Boss 战利品也会被清掉;刷新点的物品过一段时间会重新出现。

### 战斗
- **秒杀所有生物**(PgUp):对每个活着的生物打一发致死伤害，走的是正常命中流程，掉落和击杀分数都照常结算。Boss 同样能杀。
- **无视 Boss 无敌** [仅房主]:Boss 播动画、换阶段，或者同时存在多只 Boss 时也能打出伤害。
- **透视**:显示 300 米内所有活着的生物，带方框、名字、距离和血量，字号可调。每个生物和屏幕顶部中点之间有一条连线;身后的生物，连线会指向屏幕边缘。
- **自瞄**:范围 500 米，键鼠也能用，移动鼠标不会削弱吸附。强度默认 20 倍。子选项如下:
  - 锁头：瞄准生物头部。
  - 360° 锁定：身后的目标也会锁，前方有目标时优先锁前方。
  - 穿墙锁：隔着地形或船也能锁定。
  - 腰射也自瞄：不开镜也生效。
  - 按住侧键才自瞄。
- **魔法子弹**:子弹每个物理步都会重新转向锁定的目标，没有下坠。弹速倍率默认 3。
- **穿墙子弹**:你的子弹会穿过地形和船，只会被生物、玩家、NPC 挡住;贴墙开枪也能正常射出。
- **穿水子弹**:你的子弹入水后不消失，可以打中水下的鱼。
- **锁血、锁饱食度** [仅房主]
- **无限连跳、无限子弹**
- **伤害倍率**:可自定义倍数，单次伤害上限 1 亿(防止数值溢出)。

### 视角 / 联机
- **第三人称**:会在本地重建一个带你自己皮肤的身体，距离 1–15 米可调。相机只在渲染画面时移到身后，所以瞄准、交互和命中判定仍然按第一人称计算。
- **旋转**:修改发给服务器的朝向，其他玩家会看到你在转圈，你自己的视角不变。转速 10–7200 度/秒。第三人称里你也能看到自己在转。
  - 子选项"旋转时视角朝下":别人看到你一直低着头。

### 枪械
- **修复枪口购买 bug**(默认开启):修复游戏原有的 bug,换了新枪口后，原来的枪口可以重新买回来。
- **狙击枪射击间隔改为 50ms**:按枪判断(名字里带 "sniper" 或"狙击"),装什么倍镜都有效。
- **霰弹枪散布降为 20%**
- **半自动改全自动**:开火时不会自动退镜;抖动套用全自动枪模板(可在菜单里选择);霰弹枪没有后推力。
- **射速倍率**:射速提高时，会自动加快开火动画并按比例缩小每发的后坐力，避免画面抽搐;开火音效也会限流在冲锋枪射速的 2 倍以内。
- **减弱镜头后坐**:减小准星上飘和跳动。
- **减弱枪身抖动**:减小手上枪模型的晃动。全自动枪(步枪、冲锋枪)和半自动枪分别设置倍率。

### 赌场 [仅房主]
- **轮盘必胜**:开奖结果强制等于你押的颜色;押绿色可以拿 35 倍。
- **老虎机**:强制开出指定物品的传说皮肤，或恢复正常随机。

### 生成 [仅房主]
- 在准星前方生成任意鱼类或生物，支持按名字筛选。

## 已知限制

- **第三人称的身体腿不会动。** 腿部动画依赖网络数据，本地复制的身体拿不到;另外手上的枪会悬在头部附近，准星也和实际弹着点有一点偏差(相机在右肩后方)。
- **Boss 在播动画时被打死，死亡动画可能会从中途开始播放**,掉落照常。
- **伤害倍率也会作用在信天翁屎、鲸鱼岩浆打中其他生物的伤害上**,不影响打你的伤害。
- **游戏更新后，部分功能可能失效。** 修改器用到了游戏内部的字段名，如果对不上，对应功能会在日志里给出警告并自动关闭，不会导致游戏崩溃。

## 排查问题

日志在 `游戏目录\BepInEx\LogOutput.log`,常用的几行:

| 日志 | 含义 |
|---|---|
| `Patches applied.` / `Patches removed.` | 补丁的加载和卸载 |
| `Weapon tuned: ...` | 某把枪实际写入的射速、后坐力、模板等数值 |
| `Sniper rifle check: ... = True/False` | 某把枪是否被识别为狙击枪 |
| `Full-auto recoil templates: ...` | 可选的抖动模板，以及当前用的是哪一把 |
| `Kill all: hit N creatures.` | 秒杀命中的生物数量 |
| `Cleared N ground items.` | 清理掉的物品数量 |
| `Third-person body built.` / `Could not build the third-person body` | 第三人称身体是否构建成功 |

## 编译

需要安装 .NET SDK(开发时用的是 8.0),游戏里也要已经装好 BepInEx。

```
dotnet build -c Release
```

编译成功后，DLL 会自动复制到游戏的 `BepInEx\plugins\HowToFishTrainer\`。游戏目录写在 `HowToFishTrainer.csproj` 的 `GameDir` 里，如果游戏装在别的地方，需要改这一行。

Harmony 补丁是用到对应功能时才会加载的：在 BepInEx 加载插件时就打补丁会导致这个游戏启动卡死。
